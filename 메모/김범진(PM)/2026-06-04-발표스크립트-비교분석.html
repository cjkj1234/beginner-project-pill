YOLO11 선택 실제 근거: Q3 실험에서 YOLOv8x(0.91650) vs YOLO11x(0.93817) 동일 조건 비교 후 Kaggle 스코어로 결정. 발표처럼 “구조적 특성 때문에 선택”한 게 아니라 실험 결과로 선택.

🟡 추가 필요 — 발표 이후 생긴 내용

1. 모델 교체 근거가 실험 기반으로 바뀜

발표에선 C2f 구조를 이유로 YOLOv8l 선택을 정당화했지만, 실제로는 Q3 실험(YOLOv8x 0.917 vs YOLO11x 0.938 Kaggle 비교)으로 YOLO11x 채택. 선택 근거가 “구조 분석”이 아니라 “실험 검증”으로 바뀜.

2. 과적합 분석 + 최적 epoch 확정 (Q4)

발표 당시엔 에폭을 얼마나 돌려야 하는지 불명확했음. Q4 실험으로 확정:

WandB 실측 데이터 (700ep 런):

ep350 : val mAP 0.9736  ← 실질 최고점
ep550 : val mAP 0.9744  ← 200에폭 동안 고작 +0.0008
ep600+: val mAP 0.9718  ↓ 하락

overfit/loss_gap (train_loss - val_loss):

ep351 : -0.47   (학습 신호 있음)
ep551 : -0.12   (거의 수렴)
ep651 : -0.11   (수렴 완료, 더 돌려봤자 의미 없음)

Kaggle 스코어 추이:

250ep → 0.94325  ← 피크
~500ep → 0.93593 ↓

핵심 발견 — val_loss로는 과적합 감지 불가:
val_loss는 700ep까지 계속 감소하기 때문에 “val_loss가 오르면 과적합”이라는 고전적 방법이 작동 안 함.
val mAP@50도 ep200부터 1.0 고정 → 포화.
Kaggle 점수만이 유일한 진짜 신호.

overfit/loss_gap(val - train loss)은 별도 용도 — gap이 0에 수렴하면 augmentation 신호 소진, 즉 왜 plateau가 오는지 메커니즘을 설명하는 보조 지표. 과적합 감지 용도가 아님.

결론: Kaggle 기준 ep250(0.94325)이 마지막 확인 피크. ep300·ep350은 미제출이라 실제 최적값 미확정 (ep250~ep350 사이일 가능성). ep500부터는 확실히 하락. 병목 = 데이터 다양성 부족.

3. 합성 데이터 파이프라인 (Q5 가설 검증 중)

Q4 결론에서 “데이터 다양성 소진”이 병목 → 합성 데이터로 plateau 연장 시도.

scripts/build_synth_dataset.py
  GrabCut → 알약 크롭 770개
  배경 패치 390개 수집
  합성 이미지 3000장 생성 (알약 3~4개 조합)
  역빈도 가중치 → 희귀 클래스 알약 집중 생성
  • val에는 넣지 않음 (train 다양성 전용)
  • WandB artifact로 버전 관리
  • 현재 feature/synth-aug-400ep에서 실험 중

결과 검증 방법 (이중 확인):

  1. val mAP @ 같은 에폭 비교 — ep250/ep300/ep350 시점을 기존 700ep 런 동일 에폭과 비교 (기준값: ep250=0.9625, ep300=0.9669, ep350=0.9736). 높으면 synth 효과 있음.
  2. Kaggle 점수 — ep250/ep350/ep400 체크포인트 제출. 기존 피크(0.94325) 초과 시 plateau 연장 입증.
  • train_loss 곡선도 참고 — synth 런이 같은 에폭에서 기존보다 train_loss가 높으면 다양성 효과 있음 (보조 신호)
  • 최종 판정 우선순위: Kaggle score > val mAP > train_loss 추이

4. WeightedRandomSampler

발표에서 언급 없음. inverse_freq 방식으로 희귀 클래스 오버샘플링.
Iterative Stratification이 분할 단계에서 클래스 비율 보장이라면, Sampler는 DataLoader 단계에서 batch 내 희귀 클래스 등장 빈도를 높이는 것.

5. Early Stopping

발표에 없음. main 브랜치에 적용 중:

patience = 50   (50에폭 동안 개선 없으면 종료)
min_delta = 0.03  (mAP +0.03 미만은 개선으로 미인정)

val 포화 문제로 인해 이 early stopping도 실제론 완벽하지 않음 — val mAP가 1.0에서 움직이지 않으면 patience 카운터가 계속 올라가 너무 일찍 종료될 수 있음. Kaggle 제출로 외부 검증 병행 필요.

6. 병렬 실험 전략 (브랜치 분리)

발표 당시엔 단일 실험 흐름이었음. 현재는:

브랜치/실험성격핵심 설정
main파이널 런 (실험 아님)1280px, batch=4, LR 절반, synth 없음, 1500ep — 해상도 효과 확인됐으니 결과 기다리지 않고 선제 실행
feature/synth-aug-400ep실험A640px, batch=8, synth 3000장, 400ep — synth가 plateau 연장하는지 검증
별도 해상도 실험 (다른 팀원)실험BYOLO11x 200ep 기준, 증강 없음, 해상도만 올린 비교 실험

실험A/B 결과 나오면 main best + synth best로 WBF 앙상블 재구성 예정.

Q1 — 약한 모델 제거 효과 (발표 이후 추가, 이미 검증 완료)

발표 당시엔 언급 없음. WBF 앙상블에서 val mAP 낮은 모델을 제거하면 점수가 오르는지 검증. 완료.
